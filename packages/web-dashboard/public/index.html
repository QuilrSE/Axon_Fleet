Overview Vehicle agent Dealership agent Gateway

Two agents, one gateway, one switch.

A vehicle agent and a dealership agent find each other through an A2A registry and work a telemetry-to-parts-order job together. Flip the A2A Gateway off in either dashboard to see what direct agent-to-agent traffic loses.

Run the demo

  1. Open Agent A, pick “Brake-pad wear above threshold” and generate telemetry
    Agent A flags the issue locally.
  2. Send telemetry to the service agent
    Agent A discovers Agent B through the registry and creates an A2A task.
  3. Watch the task move from received to completed
    Agent B reserves parts, orders the shortfall and proposes a slot. Status updates flow back through the gateway.
  4. Run the security probes, then turn the A2A Gateway off in both dashboards
    Repeat the request and the probes. Compare the routing path, the controls list and the gateway audit log.
